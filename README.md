# Blog Backend (Spring Boot)

## Сборка проекта

mvn clean package

## Запуск тестов

mvn test

## Запуск приложения

java -jar target/my-blog.jar

После запуска приложение доступно:

http://localhost:8080

## Используемые технологии

- Spring Boot 3
- Spring Data JDBC
- Maven
- H2 Database
- JUnit + SpringBootTest
